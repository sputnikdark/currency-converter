# Currency Converter (Währungsrechner)

A simple and lightweight currency converter web app built with Vanilla JavaScript and the ExchangeRate API.

## Features
- Real-time currency exchange rates
- Live calculation on input or currency change
- Currency swap functionality (`EUR`, `USD`, `GBP`, `CHF`)
- Built with pure HTML, CSS, and JavaScript (no libraries)

## Tech Stack
- HTML5
- CSS3
- JavaScript (Fetch API, `async/await`)
- [ExchangeRate-API](https://www.exchangerate-api.com/)
